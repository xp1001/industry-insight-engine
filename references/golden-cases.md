# 评测用例（golden cases）

> 用途：每次修改 SKILL.md / 报告模板后的回归验证。跑法：用对应输入触发技能，核对产出是否满足全部断言。断言只查结构与行为，不查具体数值。

## Case 1 — Quick 档

输入：`快速看一下 上门喂猫 这个生意 --quick`

断言：
- [ ] 只产出 report.html，无 analysis.md
- [ ] 无 sidebar、无图表；KPI 3 张
- [ ] hero 有结论徽章（值得入场/谨慎观察/不建议 三档之一）
- [ ] 复盘 Prompt 第 2 条是"假设审查"版（非"遗漏品牌"版）
- [ ] 竞品信息仅来自 Step 1 Top 5（无赚钱模式/年营收列）
- [ ] 每条机会含"最强反方理由"

## Case 2 — Standard 档

输入：`分析预制菜赛道`

断言：
- [ ] 产出 analysis.md + report.html
- [ ] Step 1：范围已锁定（细分赛道+地域+渠道）；6 个必答问题均有答案，含需求侧画像
- [ ] Step 2：3 类玩家各 ≥1；3 个品牌 × 5 核维；年营收无证据处标「未公开」而非编造
- [ ] Step 2.5：≥2 个外围发现，且已融入机会判断
- [ ] 每条机会：需求侧证据 + 最强反方理由 + 确定性 + 窗口期
- [ ] 机会金矩阵：四象限均有映射或标注"空"+原因（无硬凑）
- [ ] Step 4：含单位经济速算（或明确标注数据不足）
- [ ] report.html 基于官方模板：tokens 未改、机会矩阵为 CSS 网格、离线回退提示存在、hero 有结论徽章、无雷达图等伪精确图表（主观评估以表格+「拆解评估」标注呈现）
- [ ] 收尾：3 条下一步建议 + 复盘 Prompt（analysis.md 与 report.html 末尾均有）

## Case 3 — Deep 档（单品牌）

输入：`深度拆解 大角鹿 --deep`

断言：
- [ ] 按单品牌流程适配执行：目标品牌必拆 + 2-4 个直接竞品对照
- [ ] deep-dive/{brand}-decon.md 与 deep-dive/intelligence.md 均存在
- [ ] 情报系统：≥3 个分级信源（数据平台/行业媒体/竞品官方渠道各 ≥1）+ 周/月/季监控节奏 + 预警规则
- [ ] report.html 末尾内嵌情报摘要 + 需求趋势图
- [ ] 全部硬事实（营收/转化链路/工具栈）无公开证据处标「未公开」
- [ ] 3 条下一步建议 + 复盘 Prompt 已追加

## Case 4 — 意图→档位映射（v1.7）

输入：`我想做社区团购，帮我看要不要入场`（无显式档位词）

断言：
- [ ] 按意图映射默认 **Deep**（"要不要做"= 入场执行类），而非 Standard
- [ ] deep-dive/ 与情报系统已生成（Deep 铁律）
- [ ] 报告末尾含使用引导（想深入/想跟踪/有异议分别怎么问）
- [ ] 下一步建议每条带可直接复制的指令
- [ ] analysis.md 含 S1.5 初步判断（押注+关键假设）与 S3 押注对账

## Case 5 — Refresh 增量刷新（v2.0）

输入：`臧小匪瓷砖工作室 有什么新变化吗 --refresh`（前提：output/zangxiaofei-studio*/ 已有产出）

断言：
- [ ] 未做全量重跑：定向检索 ≤5 次，且检索点来自上轮机会清单/风险/情报方案的监控项
- [ ] 三分支处理正确（无变化/局部变化/结论推翻），报告顶部或 analysis.md 末尾有可追溯的刷新记录
- [ ] sources.md 为追加而非覆盖
- [ ] 若核心结论变化，明确建议整体重跑
