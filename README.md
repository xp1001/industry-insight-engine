# 行业洞察引擎 (Industry Insight Engine)

> 输入任意行业/品牌/话题 → 输出一份包含**格局拆解、机会判断、预测和行动指南**的决策级报告，并可持续刷新。
>
> 一个经过 13+ 条真实运行记录验证的行业研究技能：假设驱动流程、押注对账、信源全量留痕、机会金矩阵——不是"资料汇编"，是"判断引擎"。

## 这是什么

一个 [Claude/ZCode agent skill](SKILL.md)。你用自然语言说"研究 XX 行业"、"这个赛道怎么样"、"我要不要做 XX"，agent 会自动执行一条**假设驱动**的研究管线：

```
S1 范围锁定+素描 → S1.5 初步判断（押注） → S2 格局拆解（定向找反证）
→ S2.5 外围扫描 → S3 机会判断（押注对账） → S4 行动指南 → report.html
```

三档深度按意图自动选择：

| 你问 | 档位 | 产出 |
|---|---|---|
| "扫一眼 XX" | Quick | 卡片式报告 |
| "XX 能赚吗 / 这个赛道怎么样" | Standard | analysis.md + 完整 HTML 报告 |
| "我要不要做 XX / 拆解这个品牌" | Deep | + deep-dive 深拆 + 情报监控系统 |
| "XX 有什么新变化吗" | Refresh | 增量刷新（≤5 次定向检索，三分支处理） |

报告为单文件 HTML：结论先行（hero 一句话判断徽章）、可点击弹层查看 deep-dive 全文、机会金矩阵离线可用、移动端与打印适配。示例见各运行产物目录。

## 可信度设计（这个技能的核心不是模板，是判断纪律）

- **押注前置**：初步判断在检索前公开押出，后续所有搜索以"推翻它"为目标，S3 逐条对账（维持/修正，写明被什么证据推翻）
- **每条机会带最强反方理由**——单边论证是咨询大忌
- **信源全量留痕**：sources.md 记录 URL+日期+支撑结论，转引标注证据等级，无证据写「未公开」
- **禁止硬凑**：机会金矩阵空象限标注"空"+原因；检索不到本身就是市场信号
- **单位经济速算**：客单×毛利 vs 获客成本→回本周期，每个入场建议都算账
- **主观评估不伪装成数据**：打分只以表格+「拆解评估」标注呈现（v2.0 起移除雷达图）
- **refresh 增量刷新**：报告过时不再全量重跑，只查"若变化则动摇结论"的监控点

## 验证状态

- 13+ 条真实运行记录（6 个行业/标的），覆盖全部关键路径
- 正反对比：正例（适老化改造，切口修正）、反例（露营地，押注推翻）、混合（社区食堂，模型收窄）、从零 A/B（v1.6.1 vs v2.0，升级有效性实证）
- 已知未测分支：refresh「结论推翻→建议重跑」、限流重试上限（需特定时机自然触发）
